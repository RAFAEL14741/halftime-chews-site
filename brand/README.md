# HalfTime Chews logo (Nov 10 2026)
Mark = a soft square chew torn in half (lime half + cream half, 2 uneven teeth). Ties to the name (half) and the pack moment (Tear.).
Picked by a blind judge over a "Half | Time" split wordmark and a half-filled circle (read as the generic contrast icon).
- logo-on-dark.svg/png: lime + cream mark, cream wordmark (black backgrounds)
- logo-on-light.svg / logo-on-lime.svg: one-color black (cream or lime backgrounds)
- mark-on-dark / mark-mono: icon only. favicon.svg: simpler 1-notch version for 16-32 px.
- Type: Inter Tight 800 (outlined), JetBrains Mono 500 tagline. Colors #D4F53C lime, #F2EEE4 cream, #0B0B0A ink.
- build.py regenerates everything from the fonts in ../fonts.
